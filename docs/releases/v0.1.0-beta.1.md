# iCloud3 Traccar v0.1.0-beta.1

首个独立仓库预览版 / First standalone preview.

- 可选实时同步：读取 iCloud3 内存，多设备、去重、重试和重启恢复。
- 主动 Recorder 历史导入：时间范围、设备选择、进度、暂停/继续和断点恢复。
- 使用现有 HA device_id 作为 Traccar uniqueId，自动创建/复用设备。
- Traccar 6.8.1 REST 设备管理 + 官方 OsmAnd HTTP 位置上传。
- 独立中英文配置、状态 sensor、脱敏诊断和 HACS 元数据。

47 项行为测试及 4 项真实 HA/SQLite Recorder 测试通过；发布前再次运行自动化测试和 hassfest。真实 Traccar、浏览器界面及 HACS 安装验证由维护者于 2026-10-14 确认通过。

## 安装 / Installation

HACS 自定义仓库：`https://github.com/mindcont/icloud3-traccar`，类型 Integration。预发布版本可能需要显示测试版。安装后重启 HA，单独添加 iCloud3 Traccar。

Manual: unzip `icloud3_traccar.zip` into `/config/custom_components/`, restart Home Assistant, then add **iCloud3 Traccar**. Configure the REST server URL and separate OsmAnd receiver URL. No Recorder or Traccar database migration is required.

## 注意 / Notes

- 默认关闭；不改变原 iCloud3 Apple 登录、实体或仪表盘。
- Token 使用 HA 原生配置存储，密码框不等于磁盘加密；OsmAnd 接收端应由可信网络或 HTTPS 网关保护。
- 速度/方向由连续实时点估算；按间隔采样不保证记录所有中间点；跨系统无法保证严格 exactly-once。
- 手工验证由维护者报告，自动化用例不等同于生产环境覆盖。

See README and docs/traccar.md for configuration, privacy, limits and rollback. SHA256SUMS covers the manual installation ZIP.
